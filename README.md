Portfolio của **Ngô Tiến Tài** là sản phẩm kết hợp giữa tư duy kỹ thuật phần mềm chuẩn mực (**Software Engineering**) và nghệ thuật thị giác web tương tác hiện đại (**Creative Web Development**).

## ✨ Tính năng Nổi bật (Key Features)

### 🌸 1. Four Seasons Adaptive Engine (Động cơ 4 Mùa)
- **4 Chế độ Mùa linh hoạt**: Xuân (*Spring*), Hạ (*Summer*), Thu (*Autumn*), Đông (*Winter*).
- **Hệ thống CSS Token thời gian thực**: Khi chuyển mùa, toàn bộ màu chủ đạo (`--accent`), hạt phát quang (`--accent-glow`), độ mờ kính (`glassmorphism`), và trích dẫn cảm xúc theo mùa sẽ biến đổi tức thì.
- **Cây 3D Tương tác (Living Tree 3D)**: Dựng bằng Three.js với hiệu ứng thị sai (parallax mouse tracking), hòa sắc cross-fade đa mùa và hệ thống hạt 3D (cánh hoa anh đào, đom đóm hè, lá phong bay, hoa tuyết mùa đông).

### ⌨️ 2. Txema Albero 3D Mechanical Keyboard Engine
- **Mô phỏng Bàn phím cơ 3D trực quan**: Tọa lạc tại phần Kỹ năng (*Skills & Technologies*), các phím bấm đại diện cho các công nghệ cốt lõi trong stack (React, Next.js, TypeScript, Node.js, Nest.js, MySQL, Docker...).
- **Tương tác Vật lý & Âm thanh**: Lắng nghe cả sự kiện gõ bàn phím vật lý thực tế lẫn click chuột, phát âm thanh switch cơ học chân thực (*Press & Release audio*).
- **HUD Thông tin Công nghệ**: Bấm vào phím bất kỳ để kích hoạt thẻ thông tin chi tiết về kinh nghiệm và ứng dụng thực tế của công nghệ đó.

### 🌐 3. Hệ thống Song ngữ Động (EN / VI Internationalization)
- **Tiếng Anh làm gốc chuẩn quốc tế** (`en`), hỗ trợ chuyển đổi sang **Tiếng Việt** (`vi`) với độ phủ dịch 100% toàn bộ trang web.
- **Nút chuyển đổi Cyber Glass Capsule cao cấp**:
  - **Con trượt từ tính đàn hồi (Magnetic Glider Thumb)** trượt với đường cong vật lý `cubic-bezier(0.34, 1.56, 0.64, 1)` và hiệu ứng squish & stretch.
  - **Quả địa cầu Vector 3D xoay 360 độ** khi đổi ngôn ngữ, tích hợp chấm radar ping trực tiếp.
  - **Sóng xung kích (Click Ripple Wave)** lan tỏa quang học khi tương tác.
  - Lưu trạng thái lựa chọn vào `localStorage` tự động.

### 🌓 4. Celestial Sun & Moon Switcher (Chế độ Ngày / Đêm)
- Chuyển đổi qua lại giữa không gian vũ trụ đêm thẳm huyền bí và giao diện ban ngày tươi sáng, thanh lịch phong cách gốm sứ châu Âu.
- Nút bấm hoạt họa Vecteezy với mặt trăng có miệng hố, mặt trời tỏa nhiệt, mây bồng bềnh và các chòm sao lấp lánh.

### ⚡ 5. Terminal Dev Preloader & Hiệu năng Cao
- Màn hình tải phim ảnh hiển thị 5 giai đoạn khởi động hệ thống WebGL, đo đạc thời gian thực và đồng bộ ngôn ngữ.
- Tối ưu hóa 100% không để xảy ra hiện tượng FOUC (Flash of Unstyled/Untranslated Content).
- Đáp ứng chuẩn xác trên mọi kích thước màn hình từ điện thoại siêu nhỏ (360px), tablet cho đến màn hình lớn 4K.

## 🚀 Cài đặt & Chạy cục bộ (Local Setup)

Dự án không yêu cầu cài đặt build step phức tạp (Webpack/Vite). Bạn chỉ cần máy tính đã cài đặt **Node.js**:

### 1. Clone kho lưu trữ
```bash
git clone https://github.com/Ristai/Portfolio_RisTai.git
cd Portfolio_RisTai
```

### 2. Khởi chạy Server
Bạn có thể khởi động ngay server tích hợp sẵn:
```bash
node server.js
```
Hoặc dùng bất kỳ static server nào bạn thích:
```bash
# Sử dụng npx serve
npx serve . -p 5500

# Hoặc dùng Live Server trong VS Code / Antigravity IDE
```

### 3. Mở trên trình duyệt
Truy cập địa chỉ:
```
http://localhost:5500  (hoặc http://localhost:3456 tùy server bạn chọn)
```
